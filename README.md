# Air Pollution-Associated Neuroinflammation and Neurodegenerative Vulnerability

### Supplementary Code and Audit Documentation

This repository accompanies the manuscript *Air Pollution-Associated Neuroinflammation and Neurodegenerative Vulnerability: A Bibliometric-Guided Mechanistic Synthesis*.

It provides supplementary analysis scripts, methodological documentation, reproducibility checks, and audit files supporting the bibliometric analyses of 540 publications, the 374-record topic-focused sensitivity analysis, and related database comparisons.

## Audit Documentation

**Audit Attachment A — Duplicate identification and record removal**

Located in `Supplementary_Code/Code/06_Record_QC_Summary/`

- `Audit_Attachment_A_217_Pairs.csv` — Initial 217 duplicate pairs.
- `Audit_Attachment_A_8_Removals.csv` — Seven subsequent eligibility exclusions and one residual duplicate removal.
- `AUDIT_A_README_CN_EN.md` — Audit documentation.
- `validate_audit_A.py` — Validation script.

- `Audit_Attachment_B_20_Terms_Aggregate.csv` — Audit of the 20 keyword burst terms in Figure 5B.

## Reproducibility

The main code package is located in `Supplementary_Code/Code/`.

Please consult `README_CN_EN.md`, the module-specific documentation, and the provided PowerShell scripts for execution instructions and reproducibility requirements.

## Data Availability

The repository contains selected derived audit outputs and analysis scripts. Complete licensed Web of Science Core Collection and Scopus exports are not publicly redistributed. Analyses requiring those records need appropriately licensed local inputs. GUI-based visualization procedures are documented separately.
